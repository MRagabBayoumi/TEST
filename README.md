# Tender AI Lab

> **معمل الذكاء الاصطناعي لكراسات الشروط والمناقصات**  
> وحدة معالجة المستندات الذكية التابعة لنظام **Kayan Catering ERP**.

---

## 📌 نبذة عن المشروع (About the Project)

مشروع تجريبي تأسيسي (Proof-of-Concept) لمعالجة كراسات الشروط الحكومية والمناقصات الكبيرة (100+ صفحة) باللغة العربية، خاصة مناقصات الإعاشة وتوريد الأغذية للمستشفيات والجامعات والجهات الحكومية.

النظام مبني لمعالجة التحديات التالية:
1. استخراج النصوص الرقمية وحفظ أرقام الصفحات بدقة تامة.
2. الكشف التلقائي عن الصفحات الممسوحة ضوئياً والمصورة.
3. تشغيل التعرف الضوئي على الحروف العربية (Arabic OCR) للصفحات المصورة والأختام بنظام التقييم متعدد المسارات.
4. معالجة وتصحيح اتجاه الحروف العربية المعكوسة (Reversed Visual Order) في ملفات الـ PDF.
5. استيعاب ملفات الـ PDF الضخمة حتى 250 ميجابايت بتدفق تجزيئي (Chunked Streaming) دون استنزاف الذاكرة.
6. استخراج جداول التغذية والمقننات المصورة والمتجهية وهيكلتها إلى صفوف وأعمدة وتنسيق Markdown.
7. التقطيع الدلالي العربي (Arabic Semantic Chunking) والحفاظ على الجداول كاملة كوحدات مستقلة.
8. التضمين المحلي وتخزين المتجهات في قاعدة بيانات Qdrant بدون أي تكاليف سحابية.
9. محرك ذكاء اصطناعي للأسئلة والأجوبة (RAG QA Engine) موثق بمصادر الصفحات والجداول بنقرة واحدة.
10. تسريع المعالجة بالتوازي عبر كافة أنوية المعالج (Multi-core Parallel Processing) وكاش فوري لبصمة الملفات (SHA-256 Deduplication).
11. واجهة مستخدم رسومية تفاعلية باللغة العربية لمتابعة الاستخراج وعرض النتائج والبحث الدلالي.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Python 3.11+ / 3.14**
- **FastAPI & Uvicorn**: خادم API سريع وخفيف ومهيكل.
- **PyMuPDF (`pymupdf`)**: فحص واستخراج الطبقات النصية الرقمية بسرعة فائقة.
- **Tesseract OCR (عبر `pytesseract`)**: التعرف الضوئي على الحروف العربية (`ara.traineddata`).
- **OpenCV & Pillow**: كشف خطوط الجداول مورفولوجياً وحجب الخطوط لحماية الحروف العربية.
- **Qdrant (Local Vector DB)**: تخزين واسترجاع المتجهات دلالياً محلياً في مسار التخزين.
- **NumPy**: توليد المتجهات الدلالية المحلية (384 أبعاد) بدون الحاجة إلى مفاتيح أو تكاليف API.
- **Pydantic v2**: التحقق من صحة البيانات وهيكلتها بدقة.
- **Tailwind CSS & Cairo Font**: واجهة ويب عصرية تفاعلية بالكامل بنظام RTL.

## 🚀 طريقة التثبيت والتشغيل (Getting Started)

### 1. استنساخ المستودع وإنشاء البيئة الافتراضية

```bash
git clone https://github.com/MRagabBayoumi/TEST.git
cd TEST

# إنشاء بيئة العمل وتفعيلها
python -m venv venv
.\venv\Scripts\activate
```

### 2. تثبيت الحزم المطلوبة

```bash
pip install -r requirements.txt
```

### 3. إعداد متغيرات البيئة

قم بنسخ ملف `.env.example` إلى `.env`:

```bash
copy .env.example .env
```

### 4. تشغيل السيرفر

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8055 --reload
```

افتح المتصفح على:
👉 **[http://127.0.0.1:8055](http://127.0.0.1:8055)**
